# Graphs

| Problem | Best Approach | Time | Space | Notes |
|---|---|---|---|---|
| [Number of Islands](number-of-islands/) | BFS/DFS flood-fill, sink land in place | O(m · n) | O(min(m, n)) | Every unsunk `"1"` starts a flood-fill that sinks the whole island to `"0"`, so each island is counted exactly once; BFS queue avoids Python's recursion limit on huge islands |
| [Max Area of Island](max-area-of-island/) | BFS/DFS flood-fill, count cells per island | O(m · n) | O(min(m, n)) | Same sink-in-place flood-fill as Number of Islands, but track the max cell count instead of the island count; a DFS that *returns* area beats a `nonlocal` counter (no reset to forget) |
| [Clone Graph](clone-graph/) | BFS with an original→clone hash map | O(V + E) | O(V) | The map doubles as the visited set — each node cloned exactly once, cycles can't loop; wire edges from the clone side (`hmap[cur].neighbors.append(hmap[nei])`) so fresh and already-cloned neighbors both connect |
| [Islands and Treasure](islands-and-treasure/) | Multi-source BFS from every gate | O(m · n) | O(m · n) | Seed the queue with all gates at once, fill level-by-level — a room's *first* fill is its shortest distance by BFS ordering; drop the visited set by only filling cells still equal to INF (the grid marks itself) |
| [Rotting Oranges](rotting-oranges/) | Multi-source BFS from every rotten orange | O(m · n) | O(m · n) | Same seeding trick as Islands and Treasure plus a fresh counter; a fresh counter of 0 → minutes so far, else -1; the visited set is only needed if the fill test is `!= 0` — with `== 1` the grid marks itself |
| [Pacific Atlantic Water Flow](pacific-atlantic-water-flow/) | Reverse multi-source BFS from both ocean borders | O(m · n) | O(m · n) | The `≤` flow rule is reversible — walk **uphill** from each ocean's border cells and everything reached can drain to that ocean; BFS from all border cells at once shares the work (O(m·n) instead of O((m·n)²) per-cell checks), and the answer is the intersection of the two visited sets |
